TVS RP 3200 Lite Print Settings

When the Windows Print window opens for the first time, check these settings once (Windows and the printer driver remember them):

1. Printer Destination:TVS RP 3200 Lite (or POS-80)
2. Paper Size (Driver):80mm / 80 x 297mm / Roll 80mm (72mm printable)
3. Margins & Scale:Margins: None (0mm) • Scale: 100%
4. Headers and Footers:Unchecked (OFF)
5. Auto-Cutter (Driver Preferences):Cut After Print / Partial Cut

Tip: Launching through Start_VaultPOS_POS.bat enables silent 1-click printing (--kiosk-printing) to the Windows default printer. Because Chromium uses the Windows driver's paper roll definition during silent kiosk printing, ensure the TVS RP 3200 Lite driver Printing Preferences are set to an 80mm Roll with 0mm margins and set as the Windows Default Printer.
